Automatiser les tâches répétitives pour se concentrer sur l'essentiel

Une collection de scripts d'administration et de maintenance écrits pour mes labs et mes projets : créer, contrôler, sauvegarder et surveiller — de façon fiable et reproductible.

Python PowerShell Bash github/narcusensei/admin-toolkit

01Démarche

Chaque tâche faite plus de deux fois mérite un script. Administrer des VM, des comptes ou des services à la main, c'est perdre du temps et surtout introduire des écarts entre les environnements.

L'ensemble est fédéré par admin.sh, une console à menu qui sert de point d'entrée unique. Mes scripts suivent trois règles : un objectif unique et clair, un mode de fonctionnement à sec (dry-run) quand l'action est sensible, et une sortie lisible qui dit exactement ce qui a été fait.

02Exemples de réalisations

Gestion d'utilisateurs Active Directory — ad/New-ADUsersBulk.ps1

Création de comptes en masse depuis un fichier CSV : uniformité des attributs, mot de passe temporaire, premier changement de mot de passe forcé.

# Import d'utilisateurs depuis un CSV (Nom;Prenom;Service) Import-Csv -Path "utilisateurs.csv" -Delimiter ";" | ForEach-Object { $login = ($_.Prenom.Substring(0,1) + $_.Nom).ToLower() New-ADUser -Name $login -GivenName $_.Prenom -Surname $_.Nom ` -Path "OU=$($_.Service),DC=lab,DC=local" ` -AccountPassword (Read-Host -AsSecureString "mdp $login") ` -ChangePasswordAtLogon $true -Enabled $true Write-Host "✔ $login créé ($($_.Service))" -ForegroundColor Green }

Maintenance du VPS — vps/vps-maintenance.sh

Mise à jour, nettoyage et état du service bot, avec résumé en fin d'exécution — exécuté régulièrement pour garder le serveur propre.

#!/usr/bin/env bash # vps-maintenance.sh — mise à jour + rapport d'état du VPS $ sudo apt update && sudo apt upgrade -y $ sudo apt autoremove -y $ systemctl is-active k4zkbot # le bot tourne-t-il ? $ df -h / # espace disque restant

Contrôle de santé — sante/healthcheck.py

Vérification périodique de services et endpoints : ping HTTP, expiration de certificats, occupation disque — et alerte en cas d'anomalie (log dédié).

# healthcheck.py — supervision légère, zéro dépendance (stdlib) # cibles définies dans healthcheck.example.json cibles = {"API Discord": "https://discord.com", "Bot local": "http://127.0.0.1:8080/health"} for nom, url in cibles.items(): try: code = urlopen(Request(url), timeout=5).status etat = "OK" if code == 200 else f"ALERTE ({code})" except URLError: etat = "INDISPONIBLE" print(f"[{etat:^15}] {nom}")
